## Автоматизация лаборатории — open source

5 открытых утилит для работы с печатными платами, STM32 и лабораторными измерениями. Технические инструкции и ограничения поддерживаются в репозиториях.

| Проект | Задача | Результат |
| --- | --- | --- |
| **[KiCad BOM → ChipDip](https://github.com/MaxStriX324/kicad-bom-chipdip)** | Подготовка BOM для ChipDip | TXT со всеми позициями и CSV для проверки |
| **[KiCad SVG → LaserGRBL](https://github.com/MaxStriX324/kicad-svg-lasergrbl)** | Подготовка слоёв PCB для лазера | PNG, G-code .nc и отчёты по каждой плате |
| **[KiCad DRL → CNC3018](https://github.com/MaxStriX324/kicad-drl-cnc3018)** | Подготовка сверловки для GRBL | GUI, TAP для GRBL, сортировка сверловки |
| **[STM32 ST-Link Flasher](https://github.com/MaxStriX324/stm32-stlink-flasher)** | Прошивка STM32F103/F405 | GUI, запись BIN, verify и лог |
| **[Rigol Oscilloscope Sorter](https://github.com/MaxStriX324/rigol-oscilloscope-sorter)** | Архивирование измерений | Архив с задержкой 60 с; Excel: 4 аналоговых + 16 цифровых |

**Рабочий процесс:** спецификация компонентов → лазерные изображения платы → сверловка CNC3018 → прошивка STM32 → архивирование измерений.

**Ограничения:** Список ChipDip не является подтверждённым заказом. Для лазера необходимо проверить размер, ноль координат, полярность, мощность и траекторию до запуска. Сверление по контуру не заменяет чистовую фрезеровку; обновлённая версия не проверена на физическом станке. Verify не подтверждает совместимость BIN с платой; аппаратные испытания ещё требуются. Экспорт 20 каналов с DHO924S + PLA2216 подтверждён; разбор отдельных вариантов BIN и форматов требует проверки.

[Описание лабораторной автоматизации на сайте →](https://maxstrix324.github.io/project/lab-automation/)

## Инженерные и аппаратные проекты

### [Библиотека компонентов для KiCad](https://github.com/MaxStriX324/kicad-component-library)

Публичная библиотека собственных символов, посадочных мест и 3D-моделей для KiCad 8–10. Есть установщик и обновление для Windows. Среди опубликованных элементов — UCC21750 и каркас трансформатора EC3503; распиновка и некоторые модели пока требуют аппаратной проверки.

`KiCad` · `Schematic Symbols` · `Footprints` · `3D`


### [Nissan Leaf HV Lab](https://maxstrix324.github.io/project/nissan-leaf-hv/)

В проекте собраны HV-батарея Nissan Leaf (24 кВт·ч), PDM и вспомогательные узлы. Исследую Battery-Emulator на ESP32, CAN-обмен и зарядную электронику; отдельно изучаю возможное применение в стационарных системах и автодоме. Интеграция ещё не является готовым испытанным решением. [Подробная публикация на DRIVE2](https://www.drive2.ru/b/741266551264528987/).

`EV` · `CAN` · `Battery` · `High Voltage`

### [ПАЗ-3206 4×4 «Черепаха»](https://maxstrix324.github.io/project/paz-3206/)

Полноприводный автобус как основа для будущего автодома. После демонтажа салона и кузовных работ перенесена аварийная дверь на место пневматической «гармошки» и установлена другая водительская дверь. Подгонка и завершение отдельных кузовных операций продолжаются. Дальше — планировка, новая проводка и инженерные системы. Гибридный привод и солнечная энергетика остаются направлениями исследования, а не готовой конструкцией. [Отчёт о переносе двери](https://www.drive2.ru/l/747022494635931215/).

[Бортжурнал и автомобильные проекты на DRIVE2 →](https://www.drive2.ru/users/maxstrix324/)
